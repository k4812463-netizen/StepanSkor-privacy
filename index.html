Шаги, события акселерометра, история активности, рост, вес, длина шага, цели, серии и настройки обрабатываются локально для подсчёта шагов, статистики, рекомендаций и напоминаний. Эти сведения не передаются оператору на сервер. Геолокация, контакты, камера и микрофон не используются. После отдельного активного согласия на рекламу Yandex Mobile Ads SDK может обрабатывать рекламный идентификатор, IP-адрес, технические сведения об устройстве, сети и взаимодействии с рекламой для загрузки, показа, таргетинга и оценки рекламы. Без рекламы основные функции доступны офлайн. Локальные данные хранятся до удаления данных активности, очистки хранилища Android или удаления приложения. Для удаления используйте «Настройки → Удалить данные активности». Отключить рекламу можно переключателем в настройках; разрешения Android можно отозвать в системных настройках. Локальное удаление не удаляет автоматически данные, уже полученные партнёром. Для вопросов, отзыва согласия и реализации применимых прав обратитесь к оператору: [alexdev26@mail.ru].
